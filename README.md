# Your Friend & Neighbour

Starter mock-up for a boutique Sydney stays and local recommendations website.

## Preview locally
Open `index.html` in your browser.

## Publish with GitHub Pages
After uploading these files:
1. Open the repository's **Settings**
2. Select **Pages**
3. Under **Build and deployment**, choose **Deploy from a branch**
4. Select `main` and `/ (root)`
5. Save

## Current pages
- `index.html` — public homepage with both apartments
- `surry-hills.html` — Surry Hills guest page
- `darlinghurst.html` — Darlinghurst guest page

The signup form and referral links are visual placeholders. They can be connected to Google Sheets and tracked redirects next.
